# Build-log summaries

One file per builder run, named `YYYY-MM-DD-<run>.md`, matching the note set in `notes/` that
started it. Summarise the build log: what the builder says it did, its departures from the design,
what it lists as verified and not verified, the build size, and the voucher balance afterwards.
Keep full logs out of the repo (the fix-pass log is 16,691 lines) unless a breakage cites them.

Everything in this repo is public.
