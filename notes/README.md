# Note sets sent to the Nimble builder

One file per run, named `YYYY-MM-DD-<run>.md` (for example `2026-11-02-full-build.md`), holding
exactly what was sent: the prompt-box text, then the attached note file, then a list of any images
attached. If a set was drafted but not sent, say so on the first line.

Everything in this repo is public.
